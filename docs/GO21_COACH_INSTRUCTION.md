# 如何幫客人開通 Baki Go 21（教練）

適用對象：使用現有 **Baki Go** 教練端的夥伴。  
這不是第二個教練 App — 你繼續用現有 Baki Go。

## 步驟

1. 打開 **Baki Go**
2. 進入 **客戶**
3. 選擇一位客人
4. 在客人頁的 **AI 陪跑** 區塊，點 **開通 21 天 AI 陪跑**
5. 確認「顧客拿到產品的日期」後啟動
6. 回到客人頁，複製 **Baki Go 21 專屬連結**
7. 用 LINE / 訊息分享給客人

## 之後你要做什麼？

- 日常陪跑由 AI 負責（客人在聊天裡拍照、說話即可）
- 需要你介入時，既有 **陪跑 / Attention / Timeline** 仍會顯示
- 不要請客人使用教練端選單或 Radar / Admin

## 安全提醒

- 連結是專屬 token，不要公開貼在公開貼文
- 不要把別人的連結轉傳給另一位客人
